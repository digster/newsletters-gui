# 2026-03-09: Icon-Only Sidebar Footer Buttons with CSS Tooltips

## What was done
- Converted sidebar footer buttons from icon+text to icon-only with CSS tooltips on hover
- Replaced `title` attributes with `data-tooltip` attributes to avoid native browser tooltip overlap
- Buttons are now fixed 32×32 squares, centered in footer with 12px gap
- Text labels visually hidden with `clip: rect()` technique (still accessible to screen readers)
- Tooltip uses `content: attr(data-tooltip)` in `::before` pseudo-element
- Tooltip arrow via `::after` pseudo-element with CSS border triangle
- Fade-in + slide-up transition on hover (150ms)
- Tooltip colors auto-invert in dark mode using `var(--fg)`/`var(--bg)` swap
- Theme button dynamically updates `data-tooltip` via `btn.dataset.tooltip` in JS

- `src/style.css` — lines 343-430: restyled footer, added tooltip CSS rules
